# Pavel Khaliullin — portfolio

Personal site for a Middle+ Full-Stack / AI developer. Vanilla HTML, CSS, and JavaScript. Open `index.html` or serve the folder:

```bash
npx serve .
```

The site is English-only.

## Files

```
index.html
style.css
script.js
favicon.svg
favicon.png
apple-touch-icon.png
photo.jpg
robots.txt
sitemap.xml
```

There is no build step. Theme is applied in a small head script to avoid a flash of the wrong color.
